# TAB Explorer — Email Marketing Assets & Template

This repository contains the standalone email HTML template and all remote-hosted image assets for TAB Explorer email outreach.

## Live Links
- **Landing Page**: [https://tab-explorer-landing-page.vercel.app/](https://tab-explorer-landing-page.vercel.app/)
- **Chrome Web Store**: [Add TAB Explorer to Chrome](https://chromewebstore.google.com/detail/ijcnikejbjffhcnblofckaihgchkiged?utm_source=item-share-cb)

## Files
- `email.html`: Production-ready HTML email using bulletproof nested `<table>` layouts and 100% inline CSS (zero external `<style>` dependencies). Compatible with Gmail, Outlook, Apple Mail, Yahoo, and mobile clients.
- `index.html`: Web preview copy of `email.html`.
- `images/`: High-resolution assets referenced via GitHub's raw CDN:
  - `icon-128.png`: 128x128 extension logo
  - `logo.png`: Full logo banner
  - `marquee-promo-tile-1400x560.png`: Hero visual showing Chrome side panel
  - `screenshot-1-overview.png`: Interface overview
  - `screenshot-2-organization.png`: Drag-and-drop & color-coding showcase
  - `screenshot-3-session-restore.png`: 1-click crash recovery
  - `screenshot-4-customization.png`: Settings and shortcuts

## How to Send
1. **Direct Copy-Paste (Gmail / Outlook Web)**: Open `email.html` in your web browser, press `Ctrl+A` / `Cmd+A` to select all, then `Ctrl+C` to copy, and paste (`Ctrl+V`) directly into the compose window.
2. **Email Services (Resend, SendGrid, Postmark, Mailchimp)**: Copy the raw HTML content of `email.html` directly into your email platform's HTML template editor.
